# Viral animasiyalı Reels — araşdırma (2026-11-19)
Mənbələr əsasən bloq/alət satıcılarıdır (rəqəmlər yoxlanmayıb). Instagram videolarını birbaşa izləmək mümkün deyil.

## Platforma siqnalları (Mosseri)
- Reels-də 3 əsas siqnal: izləmə müddəti, reach başına bəyənmə, reach başına **göndərmə (DM)**. Göndərmə yeni (izləməyən) auditoriyaya çatmaqda bir az daha ağırdır.
- Orijinallıq dəyərləndirilir → başqasının videosunu kopyalama.

## Viral animasiya səhifələri nə edir
- **Bir kontrast** (smart work vs hard work, X vs Y) — bizim bölünmüş ekran bununla eynidir.
- **Adı olan psixoloji effekt** sadə dillə (Zeigarnik, Dunning-Kruger, spotlight effect) → çox saxlanılır/göndərilir.
- **Ardıcıl vizual dil / maskot** (eyni personaj, eyni diaqram üslubu) → səhifə tanınır, izləyici qayıdır.
- **Animasiyalı altyazı** (söz-söz, qalın, yüksək kontrast) — 2026-da standart.
- Diktor hər sözünə qrafik/sayğac/diaqram kəsilir (explainer formulası). Psych2Go (YouTube) tipli animasiyalı psixologiya.
- Hekayə 3 sətir: problem → dönüş → nəticə; şəkildən ƏVVƏL hekayə təsdiqlənir (reel-studio-kit axını).

## Claude ilə reels hazırlayanlar
- HyperFrames (HTML+GSAP), Remotion (React) skill-ləri; reel-studio-kit (MIT): hekayə → səhnələr → səs → SFX kitabxanası (whoosh/riser/impact) → render → «judge».
- Bizim mühərrik eyni prinsipdir (HTML canvas → Playwright → ffmpeg). Fərq: hərəkət dili (spring/easing), kinetik yazı, SFX hər hadisəyə — M31 «Latte»-də sınandı.

## Növbəti sınaqlar (təklif)
1. Psixologiya «adlı effekt» seriyası (sabit maskot, 20–30 s).
2. Finans «kiçik xərc → böyük rəqəm» (M31 üslubu).
3. «X vs Y» kontrast — yeni işıqlı motion üslubunda.
